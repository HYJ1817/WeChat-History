# WeChat-History · 微信记忆

Windows 原生的本地微信聊天记录整理与导出工具。

## 下载

**[下载最新正式版](https://github.com/HYJ1817/WeChat-History/releases/latest)**

选择 `.exe` 当前用户安装包（无需管理员权限），或 `.zip` 便携包（解压即用）。两者均未签名，可能触发 Windows SmartScreen 或杀毒软件提示。

## 核心功能

- **微信 4.x**：只读连接本机账户，浏览与搜索会话、消息，按日期筛选。
- **离线 JSON**：导入本应用 JSON v1 或兼容的演示 JSON，只读浏览；不恢复外部图片，保留已有语音转写。
- **本地导出**：Markdown / JSON / PDF，PDF 页面可另存为 PNG；连接微信后可选图片恢复和本地语音转写。
- **场景与任务**：保存常用设置、查看任务历史，投递到普通文件夹或 Obsidian；可手动清理已完成的旧任务，不会自动清理。

## 快速开始

**环境**：Windows 10 build 19041+ 或 Windows 11，**x64**。发布版自带运行时，无需另装 .NET 或 Python；读取本机聊天需已安装并登录过微信 4.x，兼容性可能随微信版本变化。

1. 安装后打开“微信记忆”；便携版解压后运行 `微信记忆App\WeChat-History.exe`，请保留整个应用文件夹。
2. 选择账户，点击“连接微信”并确认。**连接会关闭并重启微信一次，请先保存未发送内容**，按提示完成手机确认。也可选择“导入离线 JSON…”，无需启动微信。
3. 选择会话，设置关键词或日期并应用筛选，在“导出”页选择格式，或在“任务”页生成任务。

## 隐私与清理提醒

- 微信原始数据库只读，但读取时会生成本地明文临时副本；聊天记录与导出文件请妥善保管。
- 应用无遥测，不上传聊天、不调用远程 AI；首次准备语音模型需明确同意联网下载。**本地运行不等于外部接收应用安全**，请自行确认导出位置、访问权限与同步设置。

> **任务清理是永久删除，不进回收站**。须先预览再确认，仅在本地固定 NTFS 卷且能建立保护时执行；错误可能导致部分删除，不保证回滚。NTFS 备用数据流（ADS）不受预览、指纹或防写保护，但会随文件删除，有此类资料请先备份。清理不涉及用户 JSON 原件或外部投递副本。详见[清理边界](docs/protocol.md#手动清理与保护边界)。
